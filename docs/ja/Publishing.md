# 公開用ソースコピーの準備

[English](../Publishing.md) | 日本語

このワークスペースのGit履歴を含めず、確認済みのソースコピーから公開リポジトリを作ります。リポジトリのルートで実行してください。

```bat
python scripts/export_public_source.py out/public-source
```

出力先は未作成のディレクトリを指定します。スクリプトは対象ファイルをコピーし、ハッシュの一致を確認します。MIT LICENSE、英日ドキュメント、独自テストソース、独自サンプルのバイナリ2本を含めます。Git履歴、非公開資料、第三者テスト群、生成テスト、ビルド成果物、エージェント設定、旧ビルドバッチは含めません。

対象は `scripts/export_public_source.py` のファイル・ディレクトリ一覧と拡張子で選択します。公開前に出力内容を確認してください。対象選択とハッシュ検証は、機密情報や第三者コードが含まれないことの監査ではありません。

コピー先で[ビルドとテスト](Build-and-Test.md)を行い、独立した環境で動作を確認します。構成処理で取得する第三者テスト群は、コピー先の除外対象 `Materials/` に配置されます。

```bat
cmake --preset x64-Release
cmake --build out/build/x64-Release -j 1
ctest --test-dir out/build/x64-Release --output-on-failure
```

新しい公開リポジトリへ移すときは、新しい出力先を指定して再エクスポートしてください。検証後のディレクトリ全体には第三者テスト群や生成物が増えているため、そのままコピーしないでください。`.git`、`Archive/`、`Materials/`、`Bin/`、`out/` を持ち込まず、選択されたソースから新しい履歴を作ります。

スクリプトはGit初期化、コミット、リモート作成、GitHub公開を行いません。
